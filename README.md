# SUZUKI SV400

## Личные ощущения

#### Что понравилось

- Тянет достойно - L-мотор неприхотлив к оборотам. Тяга хорошая от низов до верха.

- Легкий и сбитый - аллюминиевая рама-клетка это тема. Вес небольшой, жесткость на высоте.

- Расход в пределах 5 л.

- Небольшие размеры - плюс в междурядье.

- Звук мотора хорош.

#### Хотелось бы улучшить

- На классике после 100 км/ч ветром сдувает, на "S" возможно не так .

- Высокий центр тяжести. В движении не парит, а вот когда стоишь - мот хочет упасть.

- Карбюраторы требуют внимания (не инжектор к сожалению).

- Нет ABS. Пару раз оттормаживался до срыва - ощущения не из приятных.

## Современная приборка

Свой мот взял беспробежным, но в Японии была повреждена приборка. Промониторив рынок, решил взять с алика китайскую цифровую приборку для Titan 150. [Доки на нее есть в репе](https://github.com/dkhlystov/sv400/tree/main/Dashboard%20Controller/Titan%20150).

Крепление моделировал в sketch up. Заказал в конторе по лазерной резке. Дальше болгарка, сварка, краска.

Чтобы срастить железо с приборкой сделал контроллер.

Приборка Titan 150 сделана под тросик (скорость), поэтому пришлось разобрать ее и вывести провод от датчика холла.

Дополнительно есть возможность подключить индикатор передачи (не сильно большими трудозатратами). Не занимался пока этим.

На индикатор уровня топлива кинул датчик лампы (не нашел подходящих вариантов резистивных датчиков). На данный момент датчик топлива показывает два значения 100% и 20%.

Для тех, кто решит повторить - схемы "Splan", печатная плата "Sprint Layout", код "Arduino IDE"

#### Выводы

| Обозначение   | Описание                                                                          |
| -             | -                                                                                 |
| GND           | Общий                                                                             |
| 12V           | + 12 В                                                                            |
| S+            | Питание датчика скорости                                                          |
| SO            | Выход скорости (на Titan 150)                                                     |
| FO            | Выход датчика топлива резистивный (на Titan 150)                                  |
| SI            | Вход датчика скорости с мота                                                      |
| FIA           | Вход аналогового датчика топлива (лампы) с мота                                   |
| FID           | Вход цифрового датчика топлива (не тестил, просто добавил возможность подключить) |

Контроллер сделан на базе ESP12. Тесты и настройки доступны по Wi-Fi "SV400" (точка доступа отключается после 60 сек простоя).
Для входа используется адрес http://192.168.1.1
